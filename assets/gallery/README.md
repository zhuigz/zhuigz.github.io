# 视觉作品图片目录

主页 `index.html` 的「视觉作品」折叠画廊从这里读取图片。

## 怎么放图

**方式一（推荐，交给 AI 处理）**：把原图（任意文件名、任意格式，无需压缩）上传到 `assets/gallery/raw/` 目录，文件名以面板序号开头（如 `1-车.jpg`、`2-流浪地球.png`），然后让 Claude 拉取处理——它会自动压缩成 WebP、重命名为 `01.webp`~`08.webp` 并清理原图。

**方式二（手动）**：
1. 把作品压缩后命名为 `01.webp` ~ `08.webp`，直接放进本目录（与 `index.html` 中 `#gallery` 区块的 8 个面板一一对应）
2. 没放图片时，对应面板会显示设计好的金色光影占位视觉，不会出现破图
3. 改作品标题：编辑 `index.html` 里对应 `.fold-panel` 的 `data-title` 属性和 `.fold-cap` 文字

## 图片规格建议（防卡顿的关键）

- 格式：**WebP**（首选）或 JPG，不要直接传 AI 工具导出的原始 PNG
- 尺寸：长边 **1600px** 左右即可（折叠条和灯箱都用不到更大）
- 单张体积：**≤ 400KB**（推荐用 [squoosh.app](https://squoosh.app) 压缩，WebP 质量 80）
- 8 张总计约 2–3MB，加上 `loading="lazy"` 懒加载，手机上也不会卡

## 想换/加图

- 换图：同名覆盖即可，无需改代码
- 加图：在 `index.html` 的 `.fold-gallery` 里复制一个 `.fold-panel`，改序号和标题；建议总数不超过 12 张（再多折叠条会太窄）
