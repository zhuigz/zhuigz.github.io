# 公开仓库隐私规则

本仓库及其全部分支、提交、议题、PR、附件和 GitHub Pages 源码都按公开信息处理。未被页面链接的文件仍然是公开内容，不能被视为私密页面。

## 允许公开

- `docs/public-facts.md` 登记的身份、品牌使命与成果口径
- AI、内容创作、个人 IP、FIRE、成长系统等公共主题
- 经过概括且无法反推出私人数据的经历与成果
- 有明确出处的公开人物、作者和方法论引用

## 必须删除或泛化

- 精确生日、出生年份、区县及可识别的时间地点组合
- 中小学名称、班号、宿舍号和完整成长轨迹
- 手机号、私人微信号、二维码以及复制联系方式的脚本
- 非公众人物姓名、家庭背景、私人关系和负面评价
- 精确考试成绩、志愿细节和个人教育事件时间线
- 设备、购物平台、私人数字密码及详细日常轨迹
- 正式政治身份标签
- 可能被理解为真实现状的资产、收入和支出数据
- 精确起床、发布或日常活动时间
- 图片 EXIF、XMP 等元数据中的位置、设备或作者隐私

## 页面与仓库规则

1. 完整原稿只保存在私人归档仓库，公开页面、README、提交信息和 PR 不得链接过去。
2. 提交标题、PR 描述、审查记录、截图文件名不得包含被删除的敏感原文。
3. 联系入口在获得新的专用工作邮箱或工作账号前保持下线。
4. FIRE 等演示数据必须明确标注为“示例数据”，不得暗示为个人真实财务状况。
5. 页面引用非公众人物时一律使用角色称呼；公开人物实名引用必须说明来源。
6. 新增页面或资料前，先按本文件进行公开安全审查。

## 发布前检查

- 扫描 HTML、CSS、JavaScript、注释和文档
- 扫描图片元数据
- 检查页面源码、标题、链接及控制台错误
- 确认所有公开 URL 与核心交互正常
- 确认减少动画模式仍然生效
- 确认不存在指向私人归档或旧公开分支的链接

敏感词清单只在本地或受控环境用于扫描，不提交到公开仓库。
