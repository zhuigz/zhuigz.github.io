## 需求原始表述(用户原话要点)

- 之前只做单个独立页面,是因为体系还不成熟;现在差不多了,要整合
- **不是简单的链接跳转**,而是把所有内容结合到一起,做成"集大成者"
- 内容上要比过往任何一个网站都丰富,视觉上要足够震撼

## 待决策项(决定 PRD 走向)

1. **载体形态**:全新页面 vs 重造 index.html?(牵动"index 不链接私密页面"约定 + 公开性)
2. **内容策略**:全文照搬重排 vs 每页提取精华融合?(12 个内容页全文合并体量巨大,阅读节奏是风险)
3. **叙事结构**:人生时间线 / 体系分层 / 杂志章节式?
4. **视觉形态**:沉浸式滚动叙事 / 长卷章节式 / 整屏翻页式?

## 决策记录(2026-06-11,用户拍板)

| 决策项 | 结论 |
|--------|------|
| 载体形态 | **新建独立页面**。index.html 名片保持零改动;新页面不被站内任何页面链接,维持半私密 |
| 内容策略 | **精华融合**。每页提取核心思想 + 最强视觉段落,重新编织;不全文照搬 |
| 叙事结构 | **人生叙事弧**。底色→来路→此身→信念→远方→系统→造物→同行→成为 |
| 视觉形态 | **沉浸式滚动叙事**。滚动驱动场景演变,章节切换时场景级视觉变换;性能为硬约束 |

结论已写入正式 `prd.md`,本文档归档为过程记录。
